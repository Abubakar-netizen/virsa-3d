# Virsa3D Dataset Directory

Place your UAV drone imagery (`.jpg` / `.jpeg` files) for the Amb Temple complex in this directory.

* Raw images are excluded from version control due to file size constraints (> 2.8 GB total).
* Expected structure:
  - `data/*.JPG` or `data/*.jpeg` (UAV aerial survey captures)
  - `data/processed/` (automatically generated thumbnails and normalized frames)
